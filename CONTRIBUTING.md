# Contribuer à Bullo

Merci de l'intérêt ! Bullo est un projet personnel, fait avec l'aide d'une IA, pour des personnes neuro-atypiques.

- **Un bug ?** Ouvre une « Issue » avec le modèle proposé. Joint la sortie du bouton **Réglages > Diagnostic du lecteur** si ça concerne le lecteur.
- **Une idée ?** Ouvre une Issue « idée » : explique le problème rencontré avant la solution.
- **Du code ?** Fais un fork, une branche par changement, puis une Pull Request. Avant : `node scripts/check-frontend.js` doit afficher « syntax OK ».
- **Règles d'or :** tout reste local par défaut ; aucune dépendance réseau cachée ; accessibilité d'abord (contraste, clavier, mouvement réduit) ; textes en français clair et court.
